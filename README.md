# Manjunath G L — Data Analyst Portfolio

Premium recruiter-focused portfolio built with React + Vite.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite (usually `http://localhost:5173`).

## Customize

Edit `src/main.jsx`:

- `profile` — name, email, LinkedIn, GitHub, resume and photo paths
- `skills` — technical skills
- `projects` — project titles, descriptions, tags and links
- `certifications` — credentials

Replace assets:

- `public/assets/profile.jpg`
- `public/assets/resume.pdf`
- `public/assets/projects/project-1.png`
- `public/assets/projects/project-2.png`
- `public/assets/projects/project-3.png`
- `public/assets/certifications/certificate-1.png`
- `public/assets/certifications/certificate-2.png`

## Build for production

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Deployment

The generated `dist` folder can be deployed to Vercel, Netlify or another static hosting service.
